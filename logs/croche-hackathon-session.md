## 1단계: Croche 조사 및 신청서 초안

**결정:**
- Croche = 앱에 AI 기능을 넣을 때 인프라를 따로 만들지 않게 하는 개발 툴킷
- 웹/모바일 기반, 제공: MCP, 플러그인
- 핵심: Context·Session 관리, 비용·품질 제어, Tool 인터페이스

**신청서 문항 (3-1, 3-2, 3-3) 결정:**
- 플랫폼: Electron (Windows 데스크톱 앱, 런타임 기능 활용)
- 아이디어: PC 구석의 고양이, 할 일 추천 + 파일 열기
- 데이터: 로컬 DB + Croche에 ID·요약만 전송 (경로는 앱이 보관)
- 파일 열기 우회: Croche는 action 결정 → 앱이 파일 경로로 실행
