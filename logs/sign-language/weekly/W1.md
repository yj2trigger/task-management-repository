# 1주차 주별활동보고서 초안

> 근거: `trials.md` T-001~T-018, `constraints.md`, `figures-index.md`. 수치는 실행 로그와 결과 파일에서 옮겼다. 제출 양식(hwp)에 옮길 때 날짜·장소·참석자를 채운다. 수행자 10명 기준의 성능 수치는 **예비 결과**다.

## 1. 이번 주 목표 (신청서 1주차)
추출 파이프라인(53점·정규화·결측 마스크), 정면 단어 구간 추출 시작, 모델 설계.

## 2. 수행 내용
| 항목 | 내용 | 상태 |
|---|---|---|
| 데이터 확보 | AI-Hub API로 다운로드 자동화(데이터셋 103·636). 단어 영상 32개 파일의 대응(홀수 = 수행자별 단어 1501~3000)을 파일 앞부분만 받아 확인하고 필요한 파일만 받음 | 수행자 1~13과 검증 2명분 확보, 14~16 진행 중 |
| 추출 파이프라인 | MediaPipe Holistic(0.10.21 고정) 기반 53점(상체 11 + 양손 42)과 검출 마스크, 라벨 구간 ±0.5초 | 완료. 수행자 1명 1,500클립 중 1,499개 성공(1개는 원본 영상 손상) |
| 전처리 | 어깨 중점 이동·어깨너비 정규화, 짧은 결측 보간·긴 결측 유지, 64프레임 리샘플, 손목 기준 손 모양 채널 | 완료(단위 테스트 포함) |
| 클래스 | 단어 번호를 클래스로(이름이 같은 다른 수어가 섞이지 않게), 조건을 만족하는 후보 1,176개 중 100개(이후 50·200·300개 포갬) | 완료 |
| 모델 설계 | MLP 기준선, 양방향 GRU, TCN(파라미터 약 15만·21만·19만), 수행자 단위 폴드 분할, 같은 증강본·시드·조기 종료로 비교 | 완료 |

## 3. 결과 (예비, 수행자 10명·클래스 100개, 5폴드 × 시드 3)
| 모델 | 시험 macro-F1 | 시험 정확도 |
|---|---|---|
| MLP 기준선 | 0.621 ± 0.044 | 0.656 |
| GRU | 0.910 ± 0.014 | 0.918 |
| TCN | 0.944 ± 0.013 | 0.949 |

- 누수 검사: 모든 실행에서 학습·검증·시험 수행자가 겹치지 않음, 모든 모델이 같은 분할.
- 손 모양 채널을 빼면 모든 모델·모든 폴드에서 하락(TCN 0.944 → 0.804).
- 지연(1080p, CPU): MediaPipe 프레임당 43.2ms(complexity 1), TCN 추론 1.9ms → 약 22fps. 병목은 MediaPipe.
- 한계: 클래스 100개, 같은 스튜디오 환경, 수행자 수가 적어 일반화하지 않음. 웹캠·외부 영상 평가는 4주차.

## 4. 제약과 극복 (주요)
- 이어받기가 안 되는 다운로드 → 감시와 재시작에 견디는 대기열 (C-07, C-09)
- 필요한 것은 파일의 1%인데 30GB 단위 다운로드 → 파일 앞부분으로 내용 확인 후 필요한 파일만 (C-08)
- 추출 병목(전체 약 32시간) → 클래스를 먼저 정하고 그 단어만 추출 (C-11)
- 30fps 카메라로는 프레임 건너뜀(처리 45.6ms > 33.3ms) → 20fps 카메라와 증강으로 대응 예정 (C-12)
- 효과 없던 방법: 추정으로 파일 고르기(18.9GB 낭비), 충전·절전 해제로 밤샘 작업 유지(원인은 업데이트 재시작)
