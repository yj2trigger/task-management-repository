# 그림 목록

보고서(텍스트형·PPT형)에 쓸 그림. 가능하면 스크립트로 생성하고, 생성 스크립트와 원본 데이터(CSV)를 함께 기록한다. AI-Hub 원본 프레임 대신 좌표만 그린 스켈레톤 이미지를 쓴다.

## 항목 형식

```
### W1-02 openpose-vs-mediapipe
- 파일: 코드 레포 figures/W1-02-openpose-vs-mediapipe.png
- 생성 스크립트: (커밋 해시와 경로)
- 캡션: (무엇을 보여주나) / (무엇을 알 수 있나)
- 쓸 곳: 텍스트형 보고서 N장, PPT N쪽
- 데이터: figures/data/W1-02.csv
```

## 생성된 그림

그림과 생성 스크립트는 팀 코드 레포(`yj2trigger/sign-language-recognition`, 커밋 `67cb6e0`)의 `figures/`, `src/figures_w1.py`에 있다. 그림의 원본 수치(CSV)는 `figures/data/`에 만들어지지만, 좌표가 들어 있어 AI-Hub 이용 조건(원본을 가공한 형태의 공유 금지)을 고려해 `.gitignore`로 **레포에 올리지 않고 D 드라이브 로컬에만 둔다.** 재생성 방법: `python src/figures_w1.py <클립 npz 폴더> figures`. 영상 프레임은 쓰지 않았고 좌표 스켈레톤만 그렸다.

### W1-01 skeleton
- 파일: `figures/W1-01-skeleton.png`
- 캡션: (무엇을 보여주나) 한 클립(74프레임)의 시작·1/3·2/3·끝 시점에서 추출한 53점(상체 11점, 왼손 21점은 빨강, 오른손 21점은 파랑) / (무엇을 알 수 있나) 손이 아래에서 가슴 앞으로 올라왔다 내려가는 동작이 좌표만으로 구분되고, 반전하지 않은 영상에서 사람의 왼손이 화면 오른쪽에 나타난다.
- 쓸 곳: 텍스트형 보고서 데이터 전처리 절, PPT 전처리 쪽
- 수행자 1명(REAL01)의 클립 1개이므로 일반화하지 않는다.

### W1-02 clip-length
- 파일: `figures/W1-02-clip-length.png`
- 캡션: (무엇을 보여주나) 수행자 1명의 정면 클립 1,499개의 길이 분포(30fps, 단어 구간 앞뒤 0.5초 포함) / (무엇을 알 수 있나) 중앙값 77프레임, p95 118프레임이라 고정 길이 64프레임은 중앙값보다 짧아 대부분의 클립이 시간축으로 압축되어 들어간다.
- 쓸 곳: 텍스트형 보고서 고정 길이 선정 근거

### W1-03 hand-detection
- 파일: `figures/W1-03-hand-detection.png`
- 캡션: (무엇을 보여주나) 클립 안에서 손이 검출된 프레임 비율의 분포(로그 눈금) / (무엇을 알 수 있나) 대부분의 클립이 1.0에 가깝다(왼손 평균 0.997, 오른손 0.993). 쉬는 손도 검출될 수 있어 "검출됨"이 "움직임"을 뜻하지는 않는다.
- 쓸 곳: 텍스트형 보고서 결측 처리 절
