# 그림 목록

보고서(텍스트형·PPT형)에 쓸 그림. 가능하면 스크립트로 생성하고, 생성 스크립트와 원본 데이터(CSV)를 함께 기록한다. AI-Hub 원본 프레임 대신 좌표만 그린 스켈레톤 이미지를 쓴다.

## 항목 형식

```
### W1-02 openpose-vs-mediapipe
- 파일: 코드 레포 figures/W1-02-openpose-vs-mediapipe.png
- 생성 스크립트: (커밋 해시와 경로)
- 캡션: (무엇을 보여주나) / (무엇을 알 수 있나)
- 쓸 곳: 텍스트형 보고서 N장, PPT N쪽
- 데이터: figures/data/W1-02.csv
```
