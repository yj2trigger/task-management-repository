# 전처리·모델 설계 계획 (2026-10-18 수립)

신청서의 정량 목표(macro-F1 0.80, 15 FPS, 지연 300ms)는 임시값이다. 2주차 기준선 결과를 보고 확정한다.

## 0. 전체를 지배하는 판단

| 판단 | 근거 | 영향 |
|---|---|---|
| 학습 데이터(스튜디오 정면)와 사용 환경(노트북 웹캠)이 다르다 | 학습 정확도는 그대로 일반화되지 않는다 | 증강 필수, 웹캠 클립 몇 개를 별도 평가용으로 일찍 확보 |
| 실시간 입력에는 "수어 안 하는 구간"이 있다 | 단어 클립만 학습하면 가만히 있어도 단어 하나를 고른다 | 배경(null) 클래스 추가 (신청서에 없던 보완) |
| 수행자 51명, 클립 수는 치우쳐 있다 | 한 수행자의 반복 클립은 거의 복제본이라 섞이면 점수가 부풀려진다 | 수행자 단위 분할을 가장 먼저 확정하고 파일로 고정 |
| MediaPipe z축은 불안정하고 OpenPose 2D에는 z가 없다 | 두 소스를 같은 포맷으로 맞추려면 공통 분모가 필요 | 입력은 x, y만 사용 |

## 1. 전처리 (1~2주차)

1. **특징 벡터**: 프레임당 53점 × (x, y) = 106차원 + 검출 마스크 53차원. 정규화는 어깨 중점 이동·어깨너비 스케일. 손목 기준 상대 좌표 채널을 추가해 손 모양 정보를 살린다(효과는 비교 실험으로 확인).
2. **단어 클립 추출**: 라벨 구간 앞뒤 0.5초. 길이 분포를 먼저 보고 고정 길이 T를 정한다(90번째 백분위 근처). 선형 보간 리샘플.
3. **결측 처리**: 짧은 결측은 보간, 긴 결측은 이전 값 유지, 손 검출률이 기준 이하인 클립은 제외. 채운 프레임도 마스크는 "결측"으로 남긴다.
4. **좌우 손 방향 확인**: 입력이 거울상이면 MediaPipe 좌우 손 라벨이 바뀐다. 학습 영상과 웹캠 영상에서 같은 규칙인지 샘플로 확인. 데모는 반전 전 프레임을 추론에 쓴다.
5. **OpenPose 변환기(향후 과제용, 1주차 포함)**: 손 21점 인덱스는 같은 순서로 알려져 있으나 가정으로 두고 겹침 그림과 오차로 검증. 신뢰도 0은 마스크 0. 검증 표본은 수행자를 늘려 다시 측정(사전 조사는 수행자 1명).
6. **클래스 확정**: 클래스당 클립 수와 **서로 다른 수행자 수** 분포를 표로 만든 뒤 기준을 정한다. 수행자마다 다른 표기는 먼저 정규화. 배경 클래스는 단어 구간 밖의 정지·전환 구간에서 뽑는다.
7. **분할**: 수행자 단위 층화 그룹 분할. 분할 파일(수행자 ID 목록)을 저장하고 모든 모델이 공유. 시험 집합은 최종 1회만 사용. 어깨 기준 정규화는 샘플 단위라 정보 누수가 없다.

## 2. 모델 설계 (1~3주차)

1. **기준선**: 다수 클래스 예측, 단순 MLP(시간 평균 특징). 기준선과 비슷하면 모델이 아니라 특징·데이터가 한계라는 뜻.
2. **비교 모델**: 2층 BiGRU vs 팽창 합성곱 TCN. 파라미터 수를 비슷하게(약 10만~30만) 맞춘다.
3. **공정 비교 규칙**: 입력, 분할 파일, 조기 종료 기준(검증 macro-F1), 시드 3개, 탐색 예산(같은 횟수의 무작위 탐색)을 동일하게. 한 모델만 더 엄밀하게 재검증하고 순위를 매기지 않는다.
4. **일반화 장치**: 드롭아웃, 가중치 감쇠, 라벨 스무딩. 증강은 시간 속도 변환, 좌표 잡음, 프레임 결측, 작은 회전·스케일. 좌우 반전은 손 인덱스 교환이 필요하고 방향성 수어에서 의미가 달라질 수 있어 별도 비교.
5. **지표**: Accuracy, macro-F1, top-5, 혼동행렬, 부트스트랩 신뢰구간, 수행자별 점수 분산. 지연은 추출/추론/전체 세 구간으로 분리 측정.
