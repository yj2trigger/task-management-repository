# 제약 → 원인 → 극복 후보 → 시도 → 결과

신청서에서 요구한 필수 산출물. 효과가 없던 방법도 지우지 않고 남긴다. `시도`와 `결과`는 실제로 해 본 뒤에만 채운다.

|----|------|------|-----------|------|------|---------------|
| C-01 | GPU가 없어 학습·추론이 CPU로 제한된다 | 팀원 노트북에 GPU 없음 | 경량 모델(LSTM/GRU, 1D-CNN) 사용, 필요 시 모델 경량화 | 미시도 | 미확인(사전 조사에서 제약만 확인) | - |
| C-02 | MediaPipe 처리속도가 초당 약 20프레임이 상한이다(1080p, 1프로세스) | CPU 전용 추론 | MediaPipe 설정 조정, 카메라 프레임레이트 조정, 해상도 축소 | 미시도 | 미확인(신청서에는 해상도 축소가 효과 없던 방법의 예로 언급됨. 실제로 해 본 뒤 기록) | - |
