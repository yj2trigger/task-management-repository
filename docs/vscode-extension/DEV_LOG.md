## 2026-09-10T16:48Z ~ 18:17Z — 착수: diff 보기 · 파일 열기 · 완료 보고

**배경**: 사용자가 Cline의 세 기능(diff 보기, diff에서 클릭하면 수정 파일 일반 보기, 작업 끝나면 수정사항 정리 보고)을 공식 Claude Code 확장에도 가져오고 싶어함.

- 파일 일반 보기: VS Code 내장 명령 `workbench.action.compareEditor.openSide` 존재.

**결정 갈림길 (16:50~18:14)**:
- 사용자: "수정 전 승인 없이 diff 보기 남기는건 어렵나요?" → 자동 모드 유지 + diff 기록은 별도로 원함
- 검토한 방법: A) Git 소스 제어 탭 재사용(한계: 커밋 단위라 Claude/직접 수정 섞임, 수정 1회 단위로 안 보임, git 저장소 아니면 못 씀) / B) 훅으로 수정 전후 스냅샷 떠서 diff 탭 자동으로 열기
- 사용자: "자동으로 창에 떠서 화면 변하는건 안좋아요" → 자동으로 안 열리고 **버튼/알림으로 사용자가 열지 결정**하는 방식으로 변경 요구
- 이 지점에서 **로컬 VS Code 확장이 필요하다는 결론**(훅만으로는 VS Code 화면에 UI를 못 띄움). 방식 가(단축키만) vs 방식 나(상태바 버튼+알림) 중 **나 선택**(18:10)
- "ai로 내용 쓰면 오래걸리고 토큰 아까우니까 복사 활용 가능하죠?" → 스냅샷은 OS 파일 복사로 처리, 토큰 0 확인·안내

**구현 (18:11~18:17)**:
| 파일 | 내용 |
|---|---|
| `~/.claude/hooks/diff-snapshot.mjs` (신규) | PreToolUse에서 수정 직전 원본을 `~/.claude/diff-snapshots/`에 복사, PostToolUse에서 상태를 "수정됨"으로 기록 |
| `~/.claude/settings.json` | Edit/Write/MultiEdit/NotebookEdit 도구에 위 훅 등록(전역 — Android Studio 플러그인 쪽 수정도 같이 기록됨) |
| `~/.claude/tools/claude-diff-viewer/` (신규 폴더) | 로컬 VS Code 확장 소스 + `.vsix`. `code --install-extension`으로 설치 |

**기능**: 수정 시 우하단 알림("…파일을 수정했습니다 [diff 보기]") + 좌하단 상태바 `Claude 수정 N` 버튼 + `Ctrl+Alt+D` 단축키로 목록 → diff. diff 탭에서 `Ctrl+Alt+O`로 일반 편집기 전환. 목록 항목별 ✓로 개별 확인 완료 처리. 미확인 기록은 1주일 후 자동 정리.

**미해결로 남긴 것(이 시점)**: CLAUDE.md 완료 보고 규칙 추가는 다음 턴으로 미룸. 실제 화면 동작(알림/버튼/diff 표시) 검증 안 됨 — 사용자 확인 필요 상태로 종료.

**부수 발견**: Cline은 Claude Code 자체 파일 수정 도구를 꺼서 쓰기 때문에 이 훅 대상에서 제외됨(Cline엔 자체 diff 기능 있음).
