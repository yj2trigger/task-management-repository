## 1. 고양이 마음 4가지 (새로 추가)

고양이 자신의 기분이다. 숫자는 앱이 규칙으로 계산하고, 말은 Croche가 맡는다. 화면에 숫자 막대는 없고 표정·자세로만 보인다. 벌은 없다(아프거나 떠나지 않음).

| 마음 | 오르는 때 | 내리는 때 | 시간에 따라 |
|---|---|---|---|
| 배고픔 (0~1) | 24시간에 0 → 1 | 먹이 −0.5, 간식 −0.3 | 계속 오름 |
| 심심함 (0~1) | 사용자가 있는데 2시간 넘게 교류 없음 (+0.1/10분) | 쓰다듬기 −0.4, 대화 −0.3, 같이 쉬기 −0.5 | 밤엔 오르지 않음 |
| 서운함 (0~1) | 약속 어김 +0.4, 새벽 1시 이후 무리 +0.3, 3일 넘게 안 챙김 +0.2 | 쓰다듬기 −0.5, 간식 −0.5, 사과 −0.6 | 반감기 30분 |
| 기쁨 (−1~+1) | 칭찬·쓰다듬기 +0.3, 먹이 +0.2, 일 끝냄 +0.3, 같이 쉬기 +0.2 | 목표값 = 0.5 − 0.4×(배고픔+심심함+서운함)/3 쪽으로 | 반감기 6시간 |

- 앱 사용 시간·딴짓·쉬는 시간은 서운함 계기가 아니다.
- 저장: 원본 AD-43의 ② 적응 값 테이블. 계산: 세부설계 `01-판단`의 반감기 공식 재사용.

## 2. 고양이가 스스로 사용자를 판단하는 기준 (원본 기준만 사용)

**원본 사용자 파악기(§3.16)의 값만 읽는다.** 새 상태·새 신호는 만들지 않는다.

| 순간 | 판단 기준 | 행동 |
|---|---|---|
| 힘듦 | `지침` ≥ 0.6 **그리고** (`기분` ≤ −0.3 또는 `밤샘` 태그) | 부비기 → 꾹꾹이 |
| 졸림·하루 끝 | (`하루 마감 중` 또는 `밤샘` 태그) **그리고** `지침` ≥ 0.4 **그리고** `집중 작업` 아님 | 하품 → 곁에서 몸 말고 자기 |
| 오래 앉음 | 원본 이벤트 "90분 연속 작업" 그대로 | 기지개 |
| 일 끝냄 | 원본 AD-46 완료 추정 그대로 | 곁을 맴돎 |

**다가가지 않는 때** (원본 "말 걸 때 판단기" 기준을 말 없는 행동에도 적용)
- `회의 중`·`영상 시청` 태그, 전체화면
- `귀찮아함` ≥ 0.5 → 다가가지 않고 그 자리에서 몸만 말기
- 그 상황의 `방해 민감도`가 높음 → 부비기·꾹꾹이 대신 곁에 앉기만

**사용자가 "힘들어", "졸려", "피곤해"라고 말할 때**: 따로 계기를 만들지 않는다. 원본대로 부정적인 답 → `지침` 상승·`기분` 하락으로 들어가고, 위 기준을 넘으면 고양이가 스스로 반응한다. Croche는 문장의 감정(`user_mood`)만 알려 준다.

- 기준값 0.6·0.4·−0.3·0.5는 원본 적응 값 카탈로그(AD-15)에 넣어 학습기가 사용자별로 조정한다.
- 다가갔는데 끌어서 치우면 원본 규칙대로 `귀찮아함` +, 그 상황 `방해 민감도` +.
- 쓰다듬어 주면 "와도 되는 순간" 가중치 + (CM-05).

## 3. 표현 (원본 §3.7 이벤트 표에 더할 줄)

| 상황 | pose | 말 | 빈도 |
|---|---|---|---|
| 힘듦 | 커서 옆으로 와서 `rub` + 골골 | 없음 또는 "오늘 고생했어" | 2시간 1번 |
| 힘듦, 부비기를 받아 줌 (30초 안에 치우지 않음) | `knead` 5~8초 → 앉아서 골골 | 없음 | 하루 3번 |
| 졸림·하루 끝 | `yawn` → 활성 창 아래 `curl_sleep` | 없음, 깨면 "다시 해 볼까?" | 하루 2번 |
| 오래 앉음 | `stretch` | "같이 쭉~" | 90분 1번 |
| 일 끝냄 | `happy` 곁을 맴돎 | "수고했어냥" | 매번 |
| 배고픔 > 0.7 | `sit_look` | "배고파…" (말 걸어도 될 때만) | 반나절 1번 |
| 심심함 > 0.7 | `beg_praise` | "놀아 줘" (말 걸어도 될 때만) | 2시간 1번 |
| 서운함 > 0.5 | `sad_back`(등 돌리고 앉기) + 꼬리 탁탁 | 탓하는 말 없음. "흥" 또는 "늦었어… 걱정돼" | 계기마다 1번 |
| 서운함 풀림 | `happy` → 곁으로 | "…얼른 자라냥" | 즉시 |
| 기쁨 높음 / 낮음 | 평상시 동작 가중치 조정 (그루밍·꼬리 말기 ↑ / 웅크리기·자기 ↑) | — | 상시 |
