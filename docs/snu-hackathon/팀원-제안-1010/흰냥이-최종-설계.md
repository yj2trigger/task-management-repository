## 0. 한눈에

**흰냥이** = 회사원·개발자의 바탕화면에 사는 흰 고양이. 창 위를 걸어 다니며 곁에 있고, 자료와 일정을 먹이로 받아 할 일을 골라 주고 파일을 열어 준다. 지쳐 보이면 다가와 뺨을 부비고, 하루 끝엔 곁에서 같이 잔다. 시간이 지날수록 사용자를 기억하고 맞춰 간다.

- **플랫폼**: Windows Electron 앱(투명 창) + Croche SDK. 2인 팀, 개발 3일(10/14~16).
- **방향**: 업무 비서가 아니라 **"일하다 보면 귀엽고 가족 같은 안정감"**이 먼저. 돕는 기능은 그 위에 얹는다.
- **핵심 원칙 (§1-1)**
  - 선택지는 AI가 만들고, 앱이 제시하고, AI가 고른다. (AD-07·08·59)
  - 🆕 **몸과 안전장치는 앱, 마음과 기억은 Croche.** 앱은 "할 수 있는 것"과 "지금 해도 되는지"를, Croche는 "무엇을 왜 할지"를 기억을 근거로 정한다. (§8-13)
  - 금지 목록: **비난하거나 죄책감을 주지 않는다** (가이드 §8-1, §3.15.8). 삐짐도 걱정 표현으로만.

## 1. 구조: 누가 무엇을 하나

### 1-1. 구성요소 (§1-1)

| 구성요소 | 담당 | 하는 일 |
|---|---|---|
| 👀 관찰기 | 앱 | 활성 창·입력 강도·최근 파일·브라우저 도메인 기록, 드래그·쓰다듬기·대화 반응 기록 |
| 🧭 사용자 파악기 | 앱 | 기록 → "지금 사용자가 어떤지" 즉시 계산 (상황 태그·해석 상태) |
| 🐾 움직임 결정기 | 앱 | **0층(매 순간)**. 평상시 동작·이동 리듬·드래그 반응. 다른 구성요소를 **절대 기다리지 않음** (AD-18) |
| ⏰ 말 걸 때 판단기 | 앱 | **1층 입구(몇 초마다)**. 지금 말 걸어도 되는지만 |
| 📋 선택지 메뉴 작성기 | 앱 | **1층(말 걸 때만)**. 조건에 맞는 행동+말 묶음 3~5개 + "말 안 걸기"를 점수·근거와 함께 제시 |
| 📈 학습기 | 앱 | 오래 남는 값(고양이 설정·사용자 성향·친밀도·선택지 가중치)을 고침. Croche 제안도 여기서 검사 후 반영 |
| 🐟 먹이 창고 | 앱 | 먹인 자료·일정 정리, 상황에 맞는 참고 자료 고르기 |
| 🗺 길 찾기 | 앱 | 밟을 곳(발판) 찾기, 목적지까지 길 만들기 |
| 💬 대화 관리자 | 앱 | 대화 이어 가기·끝내기, 내역 저장 |
| 🔌 Croche 연결기 | 앱 | Croche를 부르는 **유일한 곳** (AD-11). 🆕 밖으로는 다섯 기능만 보임 (아래 1-3) |
| 🐱 고양이 화면 | 앱 | 그리기, 걷기, 말풍선, 클릭·드래그 받기, 파일 열기 |
| 📊 적응 대시보드 | 앱 | 학습 결과를 한 화면에 (데모 때 옆에 띄움) |
| 🎯🧠 선택·말·기억 | **Croche** | 메뉴 중 하나 고르기, 문장·말투, 자료 요약·태그·날짜 찾기, 질문 답, 자연어 피드백 해석, 수정 제안. 🆕 관계 기억의 원본, 사용자 문장 이해, 고른 이유, 고양이 마음을 말로 |

**담당 (AD-33)**: 조원 = 화면·감각(고양이 화면, 움직임 결정기, 사용자 파악기, 말 걸 때 판단기). yun = AI·데이터(Croche 연결기, 메뉴, 먹이, 일정, 대화, 기억). 둘의 경계는 §1-2 주고받는 형식(AD-10).

### 1-2. 앱 ↔ Croche 주고받는 형식 (§1-2)

- **말 요청**: `intent`(앱이 정함) · `facts`(사실대로 써야 할 것) · `refs`(앱이 고른 참고 자료) · `context` · `voice`(말투) · `constraints` · `allowed_actions`(붙여도 되는 버튼) · `options[]`(선택지 메뉴, 늘 "말 안 걸기" 포함) · `user_state` · `cat_memo`. 🆕 `cat_mind`(고양이 마음 값)와 그날 기억도 첨부 (CM-04).
- **말 응답**: `choice_id` · `text` · `emotion` · `action` · `variant` · `voice_patch` · `motion_patch` · `user_mood` · `task_feedback`. 🆕 `reason`(근거 기억 한 줄, AD-69).
- **검사**: 메뉴 밖 선택 → 점수 1등 실행 / 문장 길이·필수 단어·금지 표현 / enum 밖 값은 기본값. 실패 시 1회 재요청 → 템플릿.

### 1-3. 🆕 Croche 연결기의 다섯 기능 (AD-73)

| 기능 | 하는 일 |
|---|---|
| `understand(문장) → 의도` | "힘들어 / 미안 / 오늘 이거 할게 / 회의 중이야" → 정해진 의도 목록(돌봄·약속·화해·조용히). 목록 밖이면 버림 |
| `choose(후보, 사실, 마음) → 고른 것·이유·문장` | 앱이 준 안전한 후보 중 기억을 근거로 고르고 이유를 붙임 |
| `remember(한 줄)` | 관계 기억 쓰기 (함께한 일·취향·약속·서운했던 일·별명). 앱이 먼저 검사(AD-72) |
| `recall(상황) → 기억 줄들` | 지금 상황에 맞는 기억 읽기 |
| `diary(오늘 요약) → 일기 한 줄` | 하루 끝 고양이 일기 |

## 2. 하루 흐름

### 2-1. 핵심 흐름 (§2)

1. 앱을 켠다 → 고양이가 작업표시줄·창 위에 내려앉아 걷는다.
2. 공지 PDF를 끌어다 놓는다 → 냠냠 → 요약·태그 저장, 마감은 일정으로 분류해 "맞아?" 확인.
3. 다음 날 아침 → 활성 창 위로 걸어와 "D-1이야. 이것부터 하자냥" [열기].
4. [열기] → 파일이 열림 → 끝내면 완료 반응(함께 기뻐하기 / 칭찬 조르기 / 기억해 두기 / 물어보기).
5. "이거 뭐였지?" → 먹인 자료를 근거로 답 + [열기]. 안 먹인 주제면 "아직 안 먹었어".
6. 제안 거절 → 받아들이고, 그 상황 선호를 낮춤.
7. 쓰다듬기 → 하트·골골.

### 2-2. 🆕 발표 장면 9개 (§7-1)

① 기억으로 아침 인사 ② PDF 먹이기 → 마감 찾기 ③ 추천 + [열기] ④ 오래 앉으면 기지개 ⑤ "회의 중이야" → 조용히, 다음 날도 그 시간엔 조용 ⑥ 지쳐 보이면 다가와 부비기·꾹꾹이 ⑦ 밤늦게 하루 마감 중 → 곁에서 같이 잠 ⑧ 새벽까지 일함 → 등 돌린 삐짐 + "늦었어… 걱정돼" → 쓰다듬으면 화해 ⑨ **기억 끄기** → 같은 상황에서 평범한 고양이가 됨.

## 3. 고양이가 사용자를 보는 법

### 3-1. 감각 (§3.1)

- 활성 창의 제목·앱 이름·위치 (1초마다), 브라우저 **도메인**만 (활성 창 바뀔 때).
- 입력은 **분 단위 강도 3단계(없음·보통·많음)**만. 키 값은 바로 버림. 마우스 휠 횟수도 셈(읽기를 쉬는 것으로 오해하지 않게).
- 최근 연 파일(이름·경로·시각).
- **자리 비움은 화면 잠금·모니터 꺼짐·절전만** (AD-63). 입력만 5분 없으면 "조용히 곁에 있음": 말은 안 걸고 낮은 활동량으로 지냄.

### 3-2. 사용자 파악기: 시간 단위가 다른 네 종류 (§3.16, AD-04)

행동 규칙은 신호를 직접 읽지 않고 이 네 가지만 읽는다.

| 종류 | 단위 | 내용 |
|---|---|---|
| **상황 태그** | 즉시, 켜짐/꺼짐 | 집중 작업 · 쉬는 중 · 자리 비움 · 영상 시청 · 하루 시작 · 하루 마감 중 · 밤샘(자정 이후) · 마감 직전 · 오랜만에 · 회의 중(P1) |
| **해석 상태** | 분, 0~1, 시간이 지나면 0으로 | 바쁨 · 귀찮아함 · **지침**(90분 넘게 연속 작업·밤샘·부정적인 답 → 오름, 쉬면 내림) · 여유 · 기분(−1~+1) |
| **사용자 성향** | 며칠, 앱·상황별 저장 | 수다스러움 · 장난 선호 · 제안 수용 · 방해 민감도 · 선호 방법 · 선호 소재 |
| **친밀도** | 주, 0~100 | 대화가 쌓일수록 깊은 소재 허용, 호칭이 친근해짐 |

- 상황별 성향 = (그 상황 기록 수 × 그 상황 값 + k × 위층 값) ÷ (기록 수 + k). **k = 고양이의 `눈치` 성격 값** (AD-05).
- "피곤해" 같은 그날 상태는 Croche 기억에 넣지 않는다 (AD-22). 오래 남을 사실만 기억.

## 4. 🆕 고양이 마음 (§3.17, CM)

고양이 자신의 기분. 숫자는 앱이 계산하고 말은 Croche가 맡는다. 숫자 막대 없이 표정·자세로만 보인다. 벌은 없다.

| 마음 | 오르는 때 | 내리는 때 | 시간에 따라 |
|---|---|---|---|
| 배고픔 (0~1) | 24시간에 0 → 1 | 먹이 −0.5, 간식 −0.3 | 계속 오름 |
| 심심함 (0~1) | 사용자가 있는데 2시간 넘게 교류 없음 (+0.1/10분) | 쓰다듬기 −0.4, 대화 −0.3, 같이 쉬기 −0.5 | 밤엔 안 오름 |
| 서운함 (0~1) | 약속 어김 +0.4, 새벽 1시 이후 무리 +0.3, 3일 넘게 안 챙김 +0.2 | 쓰다듬기 −0.5, 간식 −0.5, 사과 −0.6 | 반감기 30분 |
| 기쁨 (−1~+1) | 칭찬·쓰다듬기 +0.3, 먹이 +0.2, 일 끝냄 +0.3, 같이 쉬기 +0.2 | 목표값 0.5 − 0.4×(배고픔+심심함+서운함)/3 쪽으로 | 반감기 6시간 |

- 앱 사용 시간·딴짓·쉬는 시간은 서운함 계기가 아니다.
- 저장: 적응 값 테이블(AD-43). 계산: 세부설계 `01-판단`의 반감기 공식.

## 5. 행동 결정

### 5-1. 행동 계획 (§3.7)

매 순간 앱이 "행동 계획" 하나를 만든다: `move_to`(어디로) · `pose`(큰 동작) · `bubble`(말풍선) · `speech`(말 요청) · `buttons` · `priority`.

**동작(`pose`)**: `idle` `walk` `sit_look` `sleep` `eat` `stretch` `beg_praise` `happy` `sad` `think` `lifted` `fall` `hide` `float` `loaf` `paw_tap` `stare` `look_up` `play_alone` + 🆕 `rub`(뺨 부비기) `knead`(꾹꾹이) `curl_sleep`(몸 말고 자기) `yawn`(하품) `sad_back`(등 돌리고 앉기)

**우선순위**: 사용자 조작 > 질문 답 > 🆕 **돌봄** > 건강 > 일정 > 추천 > 잡담 > 🆕 **조르기·삐짐** > 장난 > 평상시

- 겹치면 높은 것 하나만, 나머지는 대기열(최대 3개, 10분 지나면 버림).
- 말 걸 때는 걸어와서 → 앉아 보고 → 말풍선. 말풍선은 버튼 있으면 60초, 없으면 8초.
- 드래그 중엔 모든 이벤트 대기. 건강·일정·질문 답이 오면 장난은 즉시 끝냄.

### 5-2. 두 층 구조 (AD-07)

- **0층 (매 순간, 앱 혼자)**: 평상시 동작·이동·드래그·쓰다듬기 반응. Croche를 기다리지 않는다.
- **1층 (말 걸 때만)**: 앱이 시점과 메뉴를 정함 → Croche가 하나 고르고 말을 씀.
- **욕구 결정 (몇십 분마다, AD-58·60)**: 앱이 절대 불가만 뺀 장소·행동 메뉴를 전부 보냄 → Croche가 고양이 성향 텍스트로 1·2순위 고름 → 앱이 실현 점수로 승인/거절. 거절되면 이유별 모션(냥냥펀치·빤히 보기·올려다보기).

### 5-3. 🆕 돌봄: 고양이가 스스로 사용자를 판단해 다가감 (§3.17)

**원본 사용자 파악기 값만 읽는다.** 새 상태·신호 없음.

| 순간 | 판단 기준 | 행동 | 빈도 |
|---|---|---|---|
| 힘듦 | `지침` ≥ 0.6 **그리고** (`기분` ≤ −0.3 또는 `밤샘`) | 커서 옆으로 와서 `rub` + 골골, 말 없음 또는 "오늘 고생했어" | 2시간 1번 |
| 힘듦, 부비기를 받아 줌 | 30초 안에 치우지 않음 | `knead` 5~8초 → 앉아서 골골 | 하루 3번 |
| 졸림·하루 끝 | (`하루 마감 중` 또는 `밤샘`) **그리고** `지침` ≥ 0.4 **그리고** `집중 작업` 아님 | `yawn` → 활성 창 아래 `curl_sleep`, 깨면 "다시 해 볼까?" | 하루 2번 |
| 오래 앉음 | 원본 "90분 연속 작업" | `stretch` "같이 쭉~" | 90분 1번 |
| 일 끝냄 | 원본 AD-46 완료 추정 | `happy` 곁을 맴돎 "수고했어냥" | 매번 |

**다가가지 않는 때**: 회의 중·영상 시청·전체화면 / `귀찮아함` ≥ 0.5면 그 자리에서 몸만 말기 / 그 상황 `방해 민감도`가 높으면 곁에 앉기만.

**"힘들어", "졸려"라고 말하면**: 따로 반응하지 않는다. 부정적인 답으로 들어가 `지침`↑ `기분`↓ → 기준을 넘으면 고양이가 스스로 다가감.

기준값(0.6·0.4·−0.3·0.5)은 적응 값 카탈로그(AD-15)에 두어 학습기가 사용자별로 조정.

### 5-4. 🆕 고양이 마음 표현 (§3.17)

| 상황 | 동작 | 말 | 빈도 |
|---|---|---|---|
| 배고픔 > 0.7 | `sit_look` | "배고파…" (말 걸어도 될 때만) | 반나절 1번 |
| 심심함 > 0.7 | `beg_praise` | "놀아 줘" (말 걸어도 될 때만) | 2시간 1번 |
| 서운함 > 0.5 | `sad_back` + 꼬리 탁탁 | 탓하는 말 없음. "흥" 또는 "늦었어… 걱정돼" | 계기마다 1번 |
| 서운함 풀림 | `happy` → 곁으로 | "…얼른 자라냥" | 즉시 |
| 기쁨 높음 / 낮음 | 평상시 동작 가중치 (그루밍·꼬리 말기 ↑ / 웅크리기·자기 ↑) | — | 상시 |

## 6. 몸: 화면 위 이동 (§3.8, §3.14)

### 6-1. 발판 (밟고 설 곳)

| 층 | 방법 | 우선 |
|---|---|---|
| 창 발판 | 작업표시줄 윗변 + 보이는 창의 윗변 (가려진 구간 제외, 300ms마다 갱신) | P0 |
| 화면 선 발판 | 화면 캡처를 절반 축소 흑백으로 분석해 "상자 윗변" 가로선 찾기 (20~26ms 측정). 저장·전송 안 함 | P0 후반 |
| 요소 정보 보강 | Windows 접근성 정보로 탭·버튼 의미 붙이기 | P1 |

- 너비가 고양이 1.5배 이상이면 걷기·앉기, 1/3~1.5배면 `loaf`로 앉기만, 1/3 미만은 발판 아님.
- 커서 주변 100px, 입력 중인 칸 위, 창 오른쪽 140px(닫기 버튼)은 피함. 최대화 창 윗변·전체화면이면 숨김.

### 6-2. 움직임

- 선분 위를 걷고, 끝이면 멈추거나 돌아섬. 가까운 발판으로 점프(수평 120px·높이 200px 이내), 아래 발판으로 뛰어내리기.
- 목적지까지는 비용이 가장 작은 길(걷기 < 뛰어내리기 < 점프). 길이 없으면 `look_up`. 밟던 창이 사라지면 낙하.
- **드래그**: 5px 이상 끌면 목덜미 잡힌 `lifted`, 놓으면 아래 발판으로 낙하. "어디 데려가?"
- 몸 밖 영역은 클릭이 아래 창으로 통과.

### 6-3. 이동 리듬 (§3.14, AD-62)

- 상태별 머무는 시간: 몰두–일 4~10분 · 몰두–놀이 2~5분 · 탐색 중 30초~2분 · 조용히 곁에 있음 1~4분 · 함께 있기 1~3분 · 밤 10~20분 · 정말 자리 비움은 움직이지 않음.
- 머무름이 끝나면 확률로 움직이고, 산책(같은 발판) / 이동(다른 발판)을 나눔.
- 목적지 = 발판 선호 + 화면 구역 선호 + 앱 안 구역 선호 + 활성 창 쪽 − 최근 머문 자리.
- **배움**: 드래그로 치우면 그 구역 −0.3, 도착 30초 안에 치우면 −0.5, 같은 구역 3번이면 7일간 자동 회피("거기 싫구나. 안 갈게"), 1시간에 3번이면 덜 돌아다님. 메뉴 [여기 오지 마] [가만히 있어].

## 7. 말과 대화

### 7-1. 말투 (§3.9)

- 고정 성격(`core`) + 말 길이 1~2문장 · "냥" 빈도 · 애교 강도 · 사용자 호칭 · 말끝 습관 · 입버릇 · 쓰지 않을 표현 · 상황별 예시.
- 첫 실행 때 범위 안에서 **랜덤**으로 정함 → 사람마다 조금 다른 고양이. 데모는 시드 고정.
- "말 좀 줄여" 같은 말은 즉시 반영. 하루 1번 반응 통계로 Croche가 수정 제안 → 하루 2필드, 한 단계씩만.

### 7-2. 이름과 이름 장난 (§3.9 VC-N)

- 본래 이름 "흰냥이", 말풍선 머리줄에 표시. 사용자가 붙여 준 별명 기억.
- 장난: 자랑형(천재냥이), 삐짐형, 먹이형(정규화냥이), 배고픔형, 시간대형(야행성냥이), 박사형(냥냥박사), 별명 반응형. 계기·빈도는 앱, 이름·대사는 Croche.
- **버튼 없음.** 정해진 시간 뒤 저절로 원래 이름. "그 이름으로 해" / "원래대로 해"는 말로.

### 7-3. 말 걸기 (§3.15)

- **소재 은행**: 데이터 소재(일정·먹이·활동 변화·마일스톤), 시간 소재, 고양이 자신, 알아가기 질문, 이어 가기("면접 어땠어?"), 잡담, 놀이. 초기 약 80개 + 데이터 규칙 15개.
- **말 거는 방법**: 질문형 · 가벼운 질문형 · 감탄형 · 혼잣말형 · 다가가기형 · 조르기형.
- **시점**: 기능 말(추천·일정·건강)이 먼저, 잡담은 남은 예산의 40%까지. 말 건 뒤 10분, 대화 끝낸 뒤 20분은 잡담 없음.
- **대화**: Croche 세션으로 이어 감, 기본 6턴. 단답 2번·60초 무응답·다른 창 입력이면 마무리. 끝나면 새로 알게 된 사실 한 줄을 기억 🆕(`remember`).
- **감정·관계 대화는 말로**, 버튼은 기능 실행([열기]·[나중에]·[끝냈어] 등)에만 (AD-66). "했어?"처럼 따지는 질문 금지, "어땠어?"만.

## 8. 먹이·일정·추천

- **먹이 (§3.3)**: 파일 드롭(`.pdf` `.txt` `.md`), 링크, 한 줄 텍스트. 앱이 본문 추출·조각·검색 색인, Croche가 요약·주제·키워드·난이도·사용 조건(동의한 경우만, AD-56). 먹은 것 수첩.
- **참고 자료 고르기 (§3.4)**: 앱이 점수(전문 검색 + 태그 + 활성 창 일치 + 마감 임박 − 거절 − 오늘 연 것)로 최대 3개. Croche는 고르지 않고 답만. 없으면 "아직 안 먹었어".
- **일정 (§3.6)**: Croche가 날짜 표현을 찾고, **날짜 계산은 앱이**. 마감 D-7·D-3·D-1·당일 아침, 약속 10분 전. [끝냈어] [미뤄 줘].
- **추천 시점 (AD-47)**: "언제 막을까"가 아니라 "언제 해도 되나". 몰두 중이면 새 일 추천 안 함, 탐색 중(PC 켠 직후·자리 비움 복귀·묶음 창이 다 닫힘·일을 막 끝냄)에 1개. 추천 말에 시간을 넣지 않음(AD-48).
- **완료 (AD-46·64)**: 고양이가 추천하고 사용자가 시작한 일만. 완료 반응 4가지 중 Croche가 성향으로 고름.

## 9. 학습: 무엇이 언제 얼마나 바뀌나

| 무엇 | 언제 | 누가 | 한도 |
|---|---|---|---|
| 이동 구역 선호 | 드래그·쓰다듬기마다 즉시 | 앱 규칙 | −1~+1, 일주일마다 0 쪽으로 10% |
| 말 거는 방법·소재 가중치 | 최근 대화 10건 기준 즉시 | 앱 규칙 | 같은 입력 → 같은 결과 |
| 사용자 성향·친밀도 | 며칠·주 단위 | 학습기 | 상황 계층 + 눈치 k |
| 말투·행동 변형 | 하루 1번 | Croche 제안 → 학습기 검사 | 하루 2필드, 한 단계, 변형 ±0.1 |
| 고양이 성향 텍스트 | 하루 1번 | Croche 제안 → 학습기 검사 | 줄 수 제한, 근거·날짜 |
| 🆕 돌봄 "와도 되는 순간" | 다가간 뒤 반응마다 | 앱 규칙 | 쓰다듬으면 +, 치우면 − (CM-05) |
| 🆕 관계 기억 | 대화 끝·하루 끝 | Croche가 쓰고 앱이 검사 | 줄 길이·하루 줄 수·금지 표현 (AD-72) |

- **부품은 고정, 조합만 Croche가 늘린다** (AD-08): 동작·버튼·상황 태그 목록은 코드에, 새 선택지는 시험 → 정착 → 퇴출, 상한 300개.
- 모든 변화는 변경 기록에 "무엇이, 얼마에서 얼마로, 왜, 언제"로 남고(AD-14), 수첩에 고양이 말투로 보인다("거기 싫구나. 안 갈게").

## 10. 🆕 Croche 의존과 안전장치 (§8-13)

### 10-1. Croche가 맡는 것

| 결정 | 내용 |
|---|---|
| AD-67 | **관계 기억의 원본 = Croche Memory.** 로컬 DB는 백업 (DS-02·03). 하루 끝 고양이 일기 한 줄 |
| AD-68 | 사용자 자유 문장 이해 → 정해진 의도 목록 |
| AD-69 | 기억을 근거로 고르고 `reason`을 돌려줌 (대시보드에 표시) |
| AD-70 | 앱이 계산한 마음 값 + 그날 기억 → 말로 엮음 |
| AD-71 | **기억 끄기 장면**: 끄면 같은 아침에 "처음 보는 얼굴이냥" |
| AD-72 | Croche가 쓰는 기억 줄도 앱이 검사 |

**옮기지 않는 것**: 걷기·길 찾기, 말 걸어도 되는지, 마음 값 계산, 안전 검사, 파일 실행.

### 10-2. SDK 지원 범위별 4단계 (AD-73, OT 10/14에 확인)

| 단계 | SDK | 기억 | 고르기 응답 |
|---|---|---|---|
| 1 | 전부 됨 | Croche Memory | JSON |
| 2 | Memory API 없음 | Croche가 쓴 줄을 앱이 보관해 매번 함께 보냄 | JSON |
| 3 | 응답 모양 강제 안 됨 | 2와 같음 | 글 속 `[고름:a][이유:…]`를 앱이 읽음 |
| 4 | Croche 장애 | 앱 백업에서 읽기만 | 템플릿 + 점수 1등 |

"기억 끄기" 증명은 2·3단계에서도 성립한다.

### 10-3. 안전장치 (원본 재사용)

- 회로 차단기(AD-27), 5초 타임아웃 → 템플릿(AP-02), 장애 숨기기(AD-32), 움직임은 기다리지 않음(AD-18), 스냅숏(AD-30).
- 숫자 값은 모두 앱이 범위·하루 한도 검사(AD-02·06).
- 템플릿 이벤트(먹이 드롭·쓰다듬기·클릭·자리 비움 복귀)는 Croche 호출 없음.

## 11. 크기·투명도 (§3.13)

- 크기 50~200%, 투명도 20~100%. 우클릭 메뉴 슬라이더 또는 `Ctrl/Alt + 휠`. 크기에 따라 발판 기준도 바뀜. 말풍선 글자는 줄지 않음.
- 투명도 장난: 30% 이하로 내리면 "투명냥이", 돌아오면 "짠!", 흐린 채 쓰다듬으면 "찾았다". 숨바꼭질 등 스스로 흐려지는 장난은 P1. 사용자 설정은 건드리지 않음.
