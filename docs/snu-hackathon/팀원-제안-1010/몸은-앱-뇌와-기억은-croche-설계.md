# 몸은 앱, 뇌와 기억은 Croche: 쉬운 설계서 (2026-10-10)

> 원본 설계(요구사항-정의 (4))는 고치지 않았다. 이 문서는 제안이고, 요구사항 사본의 §8-13(AD-67~72)과 같은 내용을 쉽게 풀었다.

## 0. 한 문장
**앱은 고양이의 "몸"이라 보고·움직이고·지키고, Croche는 고양이의 "뇌"라 기억하고·이해하고·고르고·말한다.**

비유: 앱은 **운전대·브레이크·센서가 달린 자동차**, Croche는 **운전자**. 운전자가 어디로 갈지 정해도, 갈 수 없는 길이면 차가 막는다.

## 1. 누가 무엇을 하나

| | 🐱 앱 (몸·안전장치) | 🧠 Croche (뇌·기억) |
|---|---|---|
| 눈 | PC 활동 보기 (창 제목, 입력 횟수, 시각, 잠금) | — |
| 몸 | 걷기, 앉기, 자기, 그림, 말풍선, 파일 열기 | — |
| 타이밍 | **지금 말 걸어도 되나?** (회의 중·몰두 중이면 안 됨) | — |
| 후보 | **할 수 있는 것 3개**만 골라 줌 (안전한 것만) | — |
| 마음 숫자 | 배고픔·심심함·서운함·기쁨 계산 | — |
| 안전 검사 | Croche 답이 목록 안인지, 금지 표현 없는지 확인 | — |
| 기억 | 백업만 보관 | **원본.** 함께한 일, 약속, 취향, 서운했던 일, 고양이 일기 |
| 이해 | — | "힘들어", "회의 중이야", "미안" 같은 말의 뜻 알아듣기 |
| 고르기 | — | **후보 3개 중 하나를 기억을 근거로 고르고 이유를 말함** |
| 말 | — | 문장, 말투, 마음을 말로 표현 |
| 하루 정리 | — | 오늘 일을 일기 한 줄로 기억에 남김 |

**규칙 한 줄:** 앱은 **"할 수 있나, 안전한가"**, Croche는 **"무엇을, 왜"**.

## 2. 무엇이 어디에 저장되나

| 데이터 | 저장 위치 | 이유 |
|---|---|---|
| 파일 원본, 경로, 본문 | 앱 (내 PC) | 개인정보. 밖으로 안 나감 |
| 창 제목 원문, 입력 기록 | 앱 (내 PC) | 개인정보 |
| 마음 숫자, 가중치 | 앱 | 숫자가 튀면 고양이가 이상해짐 → 앱이 지킴 |
| **관계 기억** (한 줄 문장) | **Croche Memory (원본)** + 앱 백업 | "기른다" = 기억이 쌓인다 |
| 대화 중 맥락 | Croche 세션 | 대화가 자연스럽게 이어짐 |

Croche 기억에 들어가는 예:
```
- 사용자는 오후에 회의가 많다 (10/15, 거절 이유)
- 분기 보고서를 금요일까지 내기로 했다 (10/15, 약속)
- 10/15 일기: 보고서 절반 함. 늦게까지 해서 걱정됐다
- 츄르 이야기를 하면 좋아한다 (10/16)
```
앱이 쓰기 전에 검사: 한 줄 50자 이하, 하루 최대 몇 줄, 탓하는 말 금지.

## 3. 주고받는 것 (4가지 요청)

| 요청 | 앱 → Croche | Croche → 앱 | 언제 |
|---|---|---|---|
| **말하기** | 후보 3개 + 사실(마감 D-2 등) + 마음 숫자 | 고른 후보 + **이유** + 문장 | 말 걸어도 될 때 |
| **이해하기** | 사용자가 친 문장 | 의도 하나 (돌봄 / 약속 / 화해 / 조용히 / 질문 / 잡담) | 사용자가 말할 때 |
| **먹이 정리** | 파일 요약용 발췌 | 제목·요약·마감일 | 먹이 줄 때 |
| **하루 정리** | 오늘 있었던 일 요약 | 일기 한 줄 → Croche 기억에 저장 | 하루 끝 |

예: 말하기
```
앱 → Croche
  후보: [a 보고서 열기 추천, b 같이 쉬자, c 말 안 걸기]
  사실: 보고서 마감 D-2, 지금 오전 10시, 30분째 집중
  마음: 기쁨 0.6, 심심함 0.2

Croche → 앱
  고름: a
  이유: "어제 절반 했고, 오전에 집중이 잘 되는 사람"   ← Croche 기억에서
  문장: "어제 절반 했잖아. 오전에 끝내 버리자냥"
```
앱은 a가 후보 안에 있는지, 금지 표현이 없는지만 보고 실행한다.

## 4. 하루 따라가 보기

| 시간 | 일어난 일 | 앱 (몸) | Croche (뇌) |
|---|---|---|---|
| 09:00 | PC를 켬 | 고양이가 깨서 기지개, "하루 시작" 판단 | 어제 일기를 보고 "어제 늦게까지 했지? 오늘은 천천히 하자" |
| 09:30 | 보고서 파일을 고양이에게 드롭 | 냠냠 동작, 배고픔↓ 기쁨↑, 본문 추출 | 요약·마감일 뽑기, "분기 보고서, 금요일 마감" 기억 |
| 10:00 | 빈틈이 생김 | "말 걸어도 됨", 후보 3개 | 기억 근거로 "보고서 열기" 고르고 이유와 함께 말함 → [열기] |
| 14:00 | 고양이가 쉬자고 함, "회의 중이야" | 말풍선 닫고 조용히 | 뜻 이해 → "오후엔 회의가 많다" 기억 |
| 다음 날 14:00 | 같은 시간 | 후보에 "말 안 걸기" 포함 | 기억을 보고 "말 안 걸기"를 고름 → 조용히 지나감 |
| 22:00 | "힘들어"라고 침 | 커서 옆으로 와서 뺨 부비기 | 뜻 이해(돌봄) + "오늘 고생했어" |
| 01:00 | 아직 일함 | 서운함↑, 등 돌리고 앉기 | "늦었어… 걱정돼" (탓하지 않음) |
| 01:05 | 쓰다듬음 | 서운함↓ | "…얼른 자라냥" |
| 하루 끝 | — | 오늘 요약을 보냄 | 일기 한 줄을 기억에 저장 |

## 5. Croche가 실패하면
- 고양이 **몸은 그대로** 걷고 자고 반응한다 (앱은 Croche를 기다리지 않음)
- 말은 정해진 문장(템플릿)으로, 기억은 앱 백업에서 읽는다
- 3번 연속 실패하면 10분간 Croche를 부르지 않는다 (회로 차단기)
- 오류 표시는 화면에 띄우지 않고 고양이다운 행동으로 감춘다

이건 모두 팀 설계에 이미 있는 장치다 (AD-07·11·18·27·30·32). 새로 만들 것은 "기억 쓰기 검사" 하나.

## 6. Croche가 꼭 필요하다는 증명 (데모 10초)
대시보드에서 **"기억 끄기"** → 같은 아침에 고양이가 "안녕! 처음 보는 얼굴이냥".
**Croche가 없으면 매일 처음 보는 고양이**가 된다는 것을 바로 보여 준다.

## 7. 2인 분담
| 조원 (화면·감각) | yun (AI·데이터) |
|---|---|
| 고양이 화면, 걷기, 마음 숫자에 따른 동작, 말 걸 타이밍 | Croche 연결, 4가지 요청, 기억 쓰기 검사, 백업, 대시보드 |
| 바뀌는 것 거의 없음 (행동 표에 줄 몇 개) | 로컬 기억 관리 코드 대신 Croche Memory 사용 |

## 8. OT(10/14)에서 확인할 것
1. Croche Memory에 쓰기·읽기·지우기가 되나
2. 응답을 정해진 모양(고른 것·이유·문장)으로 받을 수 있나
3. 대화 세션이 이어지나

하나라도 안 되면 그 부분만 지금 설계(앱 DB가 기억 원본)로 되돌린다. Croche를 감싸는 파일이 하나라서 다른 코드는 안 바뀐다.
