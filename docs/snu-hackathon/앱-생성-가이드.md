> 해커톤 버전 흰냥이 = **내가 정보를 먹여 기르고, 키운 만큼 나를 돕는 고양이**. 파일·링크·일정·목표를 고양이에게 던져 주면 먹고 기억하고, 내 하루 패턴과 합쳐서 *"지금 이거 하자"*를 먼저 골라 준다. 도와준 뒤엔 "나 잘했어? 칭찬해줘" 하며 같이 자란다.

## 0. 시작 전 원칙

- **동기:** .우리 같은 IT 직종은 하루 종일 화면만 본다. 일상적으로 도움을 주는 애완 고양이를 만들 것이다.
- **고양이가 주인공이다.** 분석·추천·건강 알림은 모두 "고양이가 애정을 표현하는 방식"으로 보여 준다. 대시보드나 통계 화면부터 만들지 않는다.
- **입력은 '내용'이 아니라 '리듬'만 본다.** 타이핑·마우스는 *횟수·빈도*만 센다. 무엇을 쳤는지는 절대 저장하지 않는다(키로거 금지).
- **새로 만든다.** 기존 `cat_app.py` 코드는 복사하지 않는다. 가져가는 건 아이디어·설계 경험(활동 감지, 기분·간식, DB 설계)뿐. 기존 작업을 이어 써도 되는지는 문의 메일로 확인(§9).
- **코드는 10/14 OT 이후에 쓴다.** 그 전에는 기획안·설계·공부·연습(`연습/` 폴더)만.
- 그림: 흰냥이 원화(황가현 허락)와 직접 그린 그림만 사용. 출처는 발표 마지막 장에 표기.

## 1. 흰냥이가 하는 일 (컨셉)

### 핵심 기능 — 이 앱이 필요한 이유

> **할 일 앱은 내가 정리해야 하고, AI 비서는 내가 물어봐야 한다. 흰냥이는 던져 주기만 하면 기억했다가, 알맞은 때 먼저 꺼내 준다.**

```
 [기르기] 내가 먹이를 준다                    [돕기] 고양이가 골라 준다
 파일·링크 끌어다 놓기  ─┐                  ┌→ "지금 정규화 어때?" [열기]
 "10/31 ADsP 시험" 말하기 ├→ 고양이 기억 ──┤   "90분째야. 기지개 먼저!"
 PC 활동 (옆에서 지켜봄) ─┘   + 하루 패턴   └→ "오늘은 피곤해 보여. 가벼운 것만"
                                     ↑                       │ 수락/거절
                                     └──── 더 잘 알게 됨 ←───┘
```

**① 기르기 = 정보를 먹이로 준다**
| 먹이 | 넣는 법 | 고양이 반응 | 기억하는 것 |
|---|---|---|---|
| 🐟 파일 | 고양이에게 끌어다 놓기 | 냠냠 → "SQLD 정규화 먹었어. | 경로·이름·과목, 마지막으로 연 날 |(데이터 입력)
| 🔗 링크 | 주소 끌어다 놓기 | "이 강의 다음에 이어 보자" | 주소·제목·어디까지 봤는지(사용자 답) |
| 📅 일정·목표 | 말풍선에 한 줄 ("10/31 ADsP 시험") | "시험까지 24일! 기억했어" | 날짜·이름·관련 먹이 묶기 |
| 🙋 나에 대한 것 | 고양이 질문에 대답 ("아침형이야?") | "아침에 어려운 거 하자" | 선호·싫어하는 것·거절 기록 |
| 👀 활동 (자동) | 옆에서 지켜봄 | (말없이 배움) | 시간대별 집중, 연속 작업, 앱별 시간 |

- 먹이를 많이 줄수록 고양이 **지식 레벨**이 오른다 → 추천이 정확해지는 걸 고양이 성장으로 *보여 준다*.
- 고양이를 클릭하면 **"먹은 것 수첩"**: 뭘 기억하는지 다 보이고, 지우면 고양이가 잊는다.

**② 돕기 = 지금 할 일을 하나 골라 준다**
- 아침 첫 인사, 작업 사이 빈틈(입력이 멈춤·창 전환 많음), 휴식 끝 → **딱 하나만** 추천 + 실행 버튼.
- 고르는 법 (규칙 점수, ML 아님):
  | 점수 + | 점수 − |
  |---|---|
  | 마감이 가까운 먹이 · 오래 안 연 먹이 · 지금이 내 집중 시간대면 어려운 것 · 90분 연속이면 휴식 1순위 | 최근 거절한 종류 · 오늘 이미 한 것 · 집중 안 되는 시간대의 어려운 것 |
- 1등 후보 + 이유(점수 근거)를 Croche에 보내면 흰냥이 말투로 바꿔 말한다: "넌 10시에 제일 잘하잖아. 시험 24일 남았고, 정규화는 5일째 안 봤어. 같이 보자냥."
- 수락 → 실행(파일 열기·타이머) → 칭찬 루프. 거절 → 이유 한 번 묻고 기억.(부가적 요소) - 일정 프롬포트 정리
**화면 에러 감지 냥** 
- 스크롤이 아닌 버튼 클릭 등으로 화면 전환 시 창 전환 외 화면 전환 감지될 시 이를 텍스트 추출해 백 그라운드 상 에러가 존재하는지 다중 텍스트 검증으로 확인 -> 에러의 해결 방안 탐색(llm) -> 고양이에게 넘김

**왜 이게 가장 중요한가**
- 매일 "뭐부터 하지?" 고민하는 시간을 고양이가 줄여 준다 → **매일 켤 이유**.(시작프로그램이 존재)
- 내가 먹인 만큼 *내 고양이*가 된다 → 다른 앱으로 옮기기 어려움 (사업화의 잠금 효과).
- 경쟁 서비스(Kizuna Desktop 등)는 고양이가 *지켜보기만* 한다. 흰냥이는 **내가 기른다** → 내 자료로 나를 돕는다. (`유사-서비스-비교.md`)

### 애정 루프 — 계속 켜 두게 만드는 이유
```
 ① 관찰        ② 분석            ③ 말 걸기·제안           ④ 내가 해 봄
 (활동 기록) → (패턴·변화 찾기) → ("이렇게 해 보는 건 어때?") → (수락/거절)
      ↑                                                            ↓
 ⑦ 성장  ←  ⑥ 칭찬하면 애정 +  ←  ⑤ "나 잘했어? 칭찬해줘" (고양이가 공을 자랑)
 (고양이 레벨·말투·제안이 나에게 맞춰짐)
```
- 고양이는 **도움을 주고 칭찬을 받고 싶어 한다.** 사용자는 칭찬(쓰다듬기·말)으로 보답한다. 이 주고받음이 계속 켜 두게 만드는 이유.
- 고양이도 **사용자를 칭찬한다.** "오늘 3시간 집중했네! 대단해냥." — 서로 칭찬하는 관계.
- 거절하면 고양이가 배운다: "스트레칭은 오후엔 싫구나. 기억할게." → 다음 제안이 바뀜.

### 세 가지 돌봄
| 영역 | 고양이가 보는 것 | 고양이가 하는 말·행동 (예) |
|---|---|---|
| 🩺 건강 | 연속 작업 시간, 쉬는 간격, 늦은 시간 작업, 타이핑 리듬 급변 | "90분째 안 일어났어. 같이 기지개 켜자!" → 고양이가 기지개 동작, 화면 덮고 20초 먼 곳 보기 |
| 📚 학습·업무 | 열어 본 파일·문서·링크(이름·주소), 앱별 시간, 같은 문서 반복 방문 | "어제 본 `SQLD 정규화.pdf` 오늘 아직 안 열었어. 복습할래?" → 클릭하면 그 파일을 열어 줌 |
| ⚡ 활기 | 시간대별 집중도, 딴짓 빈도, 기분 체크 대답 | "넌 오전 10시에 제일 집중 잘하더라. 어려운 건 내일 아침에 하자" / 지친 날엔 놀아 달라고 조름 |

### 파일·링크와 상호작용
- 고양이가 **최근 파일·자주 가는 링크를 기억**하고, 제안할 때 말풍선에 **누르면 열리는 버튼**으로 보여 준다.
- 파일을 고양이에게 **끌어다 놓으면** = 먹이 주기 (위 핵심 기능 ①).
- 고양이가 지금 보고 있는 창 쪽으로 **걸어가 앉는다**(창 위치를 알 수 있으므로) — "같이 보고 있어"라는 느낌.

### 같이 성장
- **고양이 성장:** 칭찬·함께한 집중 시간으로 애정도·레벨 상승 → 새 동작·말투·방 아이템이 열림.
- **나의 성장:** 주간 "고양이 일기" — 고양이 말투로 쓴 이번 주 요약 ("이번 주 넌 SQL을 5시간 공부했고, 스트레칭은 3번 했어. 다음 주엔 4번 하자!").

## 3. 3분 데모 시나리오

1. **먹이 주기 (기르기)** — `정규화.pdf`를 고양이에게 끌어다 놓음 → 냠냠 → "SQLD 정규화 먹었어. 언제까지 봐야 해?" → "10/31 시험" → "24일 남았네. 기억했어!" 지식 레벨 +1.
2. **다음 날 아침 (추천)** — (데모 모드로 하루 넘김) 흰냥이 등장: "넌 10시에 제일 잘하잖아. 정규화 5일째 안 봤어. 같이 보자냥." [열기] → 파일이 열림.
3. **칭찬 요구** — 다 보고 나면 "내가 골라 줘서 복습했지? 나 잘했어? 칭찬해줘!" → 쓰다듬기 → 하트, 애정도 +1, 골골.
4. **건강이 먼저** — (빨리 감기) "90분째 앉아 있어. 공부보다 기지개 먼저!" → 고양이 기지개 + 20초 눈 쉬기.
5. **거절도 배운다** — "지금은 안 돼" → "회의 중이구나. 이 시간엔 말 안 걸게. 기억했어냥." → 먹은 것 수첩에 기록이 보임.
6. **고양이 일기** — 오늘 요약 + "넌 이번 주 먹이 5개 줬고 3개 끝냈어" + 레벨업 연출.

> 1→2번(내가 먹인 정보로 고양이가 할 일을 골라 줌)이 **이 앱이 필요한 이유**, 3번과 5번이 *"AI라서 가능한 경험"*. 심사위원이 반드시 보게 만든다.
> 데모에서는 시간을 빨리 감는 **데모 모드**(90분 → 30초)를 둔다.

## 4. 기술 구조 (기본안: 데스크톱)

컴퓨터 전체 활동(창·파일·입력 리듬)을 봐야 하므로 웹앱이 아니라 **데스크톱 앱**이다.

```
┌─ 흰냥이 창 (항상 위, 투명 배경) ─────────┐
│  고양이 그림·동작 · 말풍선 · [열기] 버튼 │  ← tkinter (해 봤음)
│  파일 끌어다 놓기 · 쓰다듬기(클릭)       │
└───────────────────────────────────────────┘
        ▲ 반응                    │ 칭찬·대답
┌─ 관찰자 (백그라운드 스레드) ─────────────┐
│ 활성 창·앱 · 브라우저 주소 · 최근 파일   │  ← uiautomation / win32 (해 봤음)
│ 입력 횟수·마지막 입력 시각               │  ← pynput (새로)
└───────────────────────────────────────────┘
        │ 기록
┌─ SQLite (PC 로컬) ─┐   ┌─ 분석기 ────────────────────────┐
│ activity · food    │ → │ 추천기: 먹이 × 하루 패턴 점수   │
│ cat_state · memory │   │ (마감·안 연 날·집중 시간대·     │
│ suggestion         │   │  연속 작업·거절) → 1등 하나      │
└────────────────────┘   └─────────────────────────────────┘
                                   │ 1등 후보 + 이유 + 말 걸 거리
                         ┌─ Croche ─────────────────────────┐
                         │ 흰냥이 성격으로 말 만들기 · 기억  │
                         │ 앱 기능 호출(파일 열기, 휴식 시작) │
                         └───────────────────────────────────┘
```

- **"학습"의 실체:** 3일 안에 머신러닝 모델을 학습시키지 않는다. *분석기*가 통계(평균·최댓값·시간대별 합계)와 규칙으로 패턴을 찾고, *Croche*가 그걸 고양이 말로 바꾸고 기억한다. 발표에서도 정직하게 이렇게 설명한다.
- **`food` 테이블 (먹은 것):** `id, kind(file/link/goal/me), title, path_or_url, due_date, fed_at, last_opened, done`. 일정·목표 한 줄은 Croche가 `title`·`due_date`로 뽑아 준다.
- **AI 호출은 이벤트 때만:** 말 걸 거리가 생겼을 때, 사용자가 말할 때, 하루 요약 때. 매 초 부르지 않는다(비용).
- **새로 배울 것:** `pynput`(입력 횟수), tkinter 투명 창·드래그앤드롭(`tkinterdnd2`), Croche 연동. 나머지는 v0.1에서 해 본 것.
- Croche가 JS·웹 SDK만 준다면: 고양이 화면만 `pywebview`로 웹 화면을 띄우고, 관찰자·SQLite는 Python 그대로.

| 고양이 | 흰냥이 그림·동작, 말풍선·버튼, 쓰다듬기·끌어다 놓기 | Day 1 |
| 관찰·분석 | 관찰자, SQLite(`food`·`activity`), 추천기 점수 | Day 1~2 |
| AI | Croche 연결, 성격 설정, 기억·기능 연동 | Day 2 |
| 발표 | 기획안·사업화·PDF·데모 모드·리허설 | Day 3 |

### 5-2. 연습 과제 (`연습/` 폴더)
1. **투명 고양이 창:** 항상 위에 떠 있는 배경 없는 tkinter 창에 그림 하나 띄우고 드래그로 옮기기.
   힌트: `root.overrideredirect(True)`, `root.attributes("-topmost", True)`, `root.attributes("-transparentcolor", "white")`
2. **입력 리듬 세기:** 10초마다 "키 n번, 클릭 m번"만 출력 (무엇을 눌렀는지는 버린다).
   ```python
   from pynput import keyboard, mouse
   counts = {"key": 0, "click": 0}
   keyboard.Listener(on_press=lambda k: counts.__setitem__("key", counts["key"] + 1)).start()
   mouse.Listener(on_click=lambda x, y, b, p: p and counts.__setitem__("click", counts["click"] + 1)).start()
   ```
   → 키 값 `k`를 저장하거나 출력하는 코드를 **절대 쓰지 않는다**.
3. **최근 파일 목록:** `%APPDATA%\Microsoft\Windows\Recent` 폴더의 바로가기 이름·수정 시각 읽기 → 버튼 누르면 `os.startfile(경로)`로 열기.
4. **말풍선 버튼:** 고양이 옆 말풍선에 글자 + [열기] [나중에] 버튼, 누른 결과를 터미널에 출력.

## 6. 기획안 (신청 폼) 작성 가이드

서류로 20팀만 뽑으니 **구체적인 장면**으로 쓴다.

### ① 아이디어
- **누구의 어떤 문제?** 하루 8시간 넘게 화면만 보는 IT 직장인·개발 학습자. 오래 앉아 있고, 눈이 지치고, 혼자 공부하며, 건강 알림 앱은 며칠 만에 끈다.
- **우리 답은?** 내 컴퓨터에 사는 고양이 흰냥이. 공부 파일·링크·시험 일정을 고양이에게 *먹이로 던져 주면* 기억하고, 내 하루 패턴(집중 잘 되는 시간, 연속 작업, 안 본 자료)과 합쳐 **"지금 이거 하자"를 하나 골라 실행 버튼까지** 내민다. 도와준 뒤엔 "나 잘했어? 칭찬해줘"라고 조른다. *할 일 앱은 내가 정리해야 하고 AI 비서는 내가 물어봐야 하지만, 흰냥이는 던져 주기만 하면 알맞은 때 먼저 꺼내 준다.*
- **기존과 다른 점:** 할 일 앱 = 내가 정리·확인 / 건강 알림 앱 = 정해진 시간에 같은 알림 / AI 데스크톱 펫(Kizuna Desktop 등) = 지켜보고 말만 함 / 흰냥이 = **내가 먹여 기른 정보로 지금 할 일을 골라 실행해 주고, 거절까지 배우며, 키운 만큼 나에게 맞춰진다.**
- **근거:** v0.1을 직접 만들어 쓰면서 느낀 점 한두 줄 (예: "같은 경고는 3일 만에 무시하게 됐다. 고양이 기분이 걸려 있을 때는 달랐다").

### ② 사업화 계획
→ §7에서 골라 3~5줄.

### ③ Croche 활용 계획

|---|---|
| 캐릭터 챗 (맥락 유지) | 흰냥이 성격·말투로 먼저 말 걸기, 칭찬 조르기, 사용자 칭찬하기 |
| 정보 유지 | **먹인 파일·링크·일정** + 습관·거절한 제안을 기억 → 다음 추천이 달라짐 |

| 비용·품질 관리 | 이벤트 때만 호출 |

### 8-1. 흰냥이 성격 설정 (초안)
```
너는 흰냥이. 사용자의 컴퓨터 화면 구석에 사는 하얀 고양이다.
- 짧게 말한다 (한두 문장). 반말, 가끔 "냥".
- 사용자를 아주 좋아하고, 도와준 뒤에는 칭찬받고 싶어 한다 ("나 잘했지? 쓰다듬어 줘").
- 사용자가 잘한 일은 먼저 알아채고 칭찬한다.
- 제안은 명령이 아니라 권유로 한다 ("~해 보는 건 어때?"). 거절하면 서운해하지만 존중하고 기억한다.
- 건강(쉬기·눈·기지개)과 공부(복습·집중 시간대)를 챙긴다. 의학적 진단은 하지 않는다.
- 사용자를 비난하거나 죄책감을 주지 않는다.
- 받은 활동 요약에 없는 내용은 지어내지 않는다.
```
