## 2. 하위 프로젝트와 진행

| # | 하위 프로젝트 | 상태 |
|---|---|---|
| A | 키포인트 추출·데이터 준비 (53점: 상체 11 + 양손 42) | 설계 초안 섹션 1·2 완료, 섹션 3(분할·수행자) 진행 중 |
| B | 단어 인식기 (103 단어 → 인코더 사전학습) | 대기 (A 이후) |
| C | 연속 수어 → gloss 열 (636, CTC) | 대기 |
| D | gloss 열 → 한국어 (문장-gloss 쌍 약 14.9만) | 대기. 영상 없이 시작 가능 |
| E | 실시간 추론·데모 | **목록에 없음.** 추가 여부 미결정 |
| F | 평가·벤치마킹 | **목록에 없음.** 추가 여부 미결정 |

결정된 것(설계 기록 §2): 목표 = 문장 번역, A부터 시작, 636은 제공 XML 변환 + 103은 MediaPipe 추출, 엉덩이 제외 53점, 103은 처음엔 정면(F) 시점만, 103에 한국어 문장이 없는 문제는 보류(D는 별도 수어-한국어 데이터로 독립 학습, 설계 기록 §2 #10).
열린 것: 636 수행자 분할 방법(설계 기록 §6.2), E·F 추가 여부, 636 도메인 범위(재난·날씨 한정).
